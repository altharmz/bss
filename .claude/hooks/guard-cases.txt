# Regression cases for guard.sh, run by .claude/hooks/test-guard.sh (and by the
# pre-commit hook whenever .claude/ changes). One case per line:
#   allow <command>      expected exit 0
#   block <command>      expected exit 2
#   allow-ml / block-ml  the same, with every literal \n in the command turned into a newline
#   <any of these>@cloud the case runs with CLAUDE_CODE_REMOTE=true (cloud mode); all
#                        others run with it removed, wherever the suite runs
#   <...>@remote-false   the case runs with CLAUDE_CODE_REMOTE=false (not cloud mode)
# Paths are relative to the project root; absolute ones are written $CLAUDE_PROJECT_DIR
# (test-guard.sh expands it), so the cases pass on the workstation and in the cloud.
